GNKG self-hosted web fonts
==========================

Latin-subset variable woff2 files for Fraunces, Manrope and JetBrains Mono, served from here so visitors
never contact a third-party font host. Rules: ../css/fonts.css (font-display: swap).

Licence: SIL Open Font License 1.1 for all three families. The full text, with each copyright notice, is in
OFL-fraunces.txt, OFL-manrope.txt and OFL-jetbrainsmono.txt. The fonts are unmodified and not renamed.

Sources, file sizes and sha256 hashes, and how to refresh them: docs/SELF_HOSTED_FONTS.md in the repository.
